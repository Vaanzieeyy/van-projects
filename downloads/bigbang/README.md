# Unduhan Banner METAVERSE — Big Bang

- [Download PSD berlayer](./METAVERSE-BigBang-Layered.psd?raw=true)
- [Download PSD + font + panduan](./METAVERSE-BigBang-PSD-dan-Font.zip?raw=true)

Ukuran: 2172 × 724 piksel. Ada dua grup: tampilan asli dengan potongan raster,
dan versi rekonstruksi editable dengan 8 teks native dan 3 shape vektor.
Untuk menyunting, sembunyikan grup 01 dan tampilkan grup 02.
Foto ketiga koper tetap satu area raster pada resolusi sumber. PSD tidak
meningkatkan resolusi foto. Pasang font dari ZIP sebelum menyunting teks.
