# Metaverse Koper — Marketing Calendar Indonesia 2027

Snapshot: 18 November 2026, Asia/Jakarta.

[Unduh workbook Excel](./Metaverse_Koper_Marketing_Calendar_2027.xlsx?raw=true) · [Unduh daftar event CSV](./Metaverse_Koper_2027_Events.csv?raw=true). Berisi README, ringkasan, daftar event, 365 tanggal, 12 kalender bulanan, campaign plan, sumber dan log verifikasi.

**Batas data:** akses langsung ke sumber pemerintah / PBB yang diberikan pengguna ditolak jaringan (CONNECT 403). LN dan CB menggunakan data sekunder holidays 0.109. Hari nasional dan internasional bertanggal tetap tetap memerlukan cek primer. Awal Ramadan 8 Februari masih perkiraan. Libur sekolah dan momentum komersial adalah window rencana, bukan pengumuman resmi. Tidak ada target, anggaran atau penjualan aktual yang diasumsikan.

Kalender bulanan dan harian adalah snapshot; perubahan event perlu diperbarui pada tab terkait. File tidak tersinkron otomatis dengan situs sumber.

CSV dapat diimpor ke Google Sheets, tetapi format biru tersedia lengkap di XLSX.
